# Programming Portfolio

A clean portfolio of beginner-friendly Python, C++, and Pep/assembly-style projects.

This repo focuses on readable code, clear input/output behaviour, and short project-level documentation. It is built from class practice work that has been organised, cleaned, and tested.

## How to run

Python examples:

```bash
python3 projects/simple-calculator/main.py
```

C++ examples:

```bash
g++ -std=c++17 projects/gcd-calculator/main.cpp -o gcd-calculator
./gcd-calculator
```

Pep/assembly examples should be run in a compatible Pep simulator.

## About

These projects show steady practice in programming fundamentals: input/output, loops, functions, arrays/lists, dictionaries/maps, string processing, algorithms, and basic numerical computing.
