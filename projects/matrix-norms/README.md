# Matrix Norms

Calculates three matrix norms without external libraries:

- 1-norm: maximum absolute column sum
- infinity norm: maximum absolute row sum
- Frobenius norm: square root of the sum of squared entries

## Concepts used

- nested loops
- functions
- matrix input
- formatted floating-point output

## Run

```bash
python3 main.py
```

## Example input

```text
2 3
1 -2 3
4 5 -6
```
